# Yocto

Yocto 方向围绕嵌入式 Linux 系统构建开展实践，可提出配方维护、软件层集成、镜像构建、构建验证与文档相关任务。

## 上游入口

- [Yocto Project](https://www.yoctoproject.org/)
- [Yocto Project 官方文档](https://docs.yoctoproject.org/)
- [Yocto Project 源码入口](https://git.yoctoproject.org/)

## 实践记录

任务开始前记录发行分支、软件层及其版本、目标机器、发行配置和构建环境。提交成果时提供实际构建命令、镜像或软件包验证结果，以及对应上游仓库的贡献链接。

参与者根据修改内容确认所属软件层和维护社区，并按照其贡献流程提交成果。
本计划的作者及任务要求的导师均使用本人真实姓名的英文全称签署 DCO，
中文姓名使用完整拼音；通常将姓名各部分的首字母大写，也可以将姓氏全部大写。
提交前按
[提交规范](../../CONTRIBUTING.md#提交格式与-dco)核对作者和签署信息。

任务发布方式见[贡献指南](../../CONTRIBUTING.md)，年度安排见 [programs/](../../programs/README.md)。
