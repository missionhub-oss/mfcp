# 导师指导

## 导师职责

- 帮助参与者理解项目、准备环境并选择适合的任务。
- 在任务开始前确认范围、交付内容与验收条件。
- 与参与者约定沟通频率、渠道和问题反馈方式。
- 指导问题分析、方案设计、验证和上游贡献流程。
- 以本人真实姓名登记并签署导师 DCO，审核参与者的作者姓名与签署信息，按[提交规范](../CONTRIBUTING.md#提交格式与-dco)提供指导。
- 根据实际证据评估成果，记录指导意见与等级建议。

## 参与者职责

- 按约定更新进展，提供可复现的问题描述和实际运行结果。
- 提前说明开发条件、时间安排及影响任务完成的问题。
- 处理评审意见，并注明获得的指导和引用的资料。
- 使用本人真实姓名配置 Git 作者信息并签署 DCO，提交前核对姓名和邮箱。
- 在任务完成、暂停或交接时整理成果与剩余事项。

## 协调安排

组织者在每期公告中明确导师名单和协调渠道。导师暂时无法继续指导时，组织者与参与者协商任务安排并记录交接情况。导师对任务成果提供评估，上游维护者按照社区流程决定贡献是否合并。
