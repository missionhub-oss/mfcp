# 参与规则

Mission Forge Contributor Program（MFCP）面向希望参与真实开源项目的学习者与开发者，实践方向包括 Zephyr、Linux、Yocto 和 Humanize。

Linux 方向包含 openRuyi 的软件包维护、系统验证与文档贡献，资料和上游入口见
[Linux 项目说明](../projects/linux/README.md#openruyi-实践)。

## 参与流程

1. 按[参与者注册说明](../participants/README.md) Fork 仓库，以本人真实姓名的英文全称签署 DCO，中文姓名使用完整拼音；通常将姓名各部分的首字母大写，也可以将姓氏全部大写。提交本人身份文件的 PR，经过审核合并后，阅读项目资料与当期公告，选择实践方向。
2. 按[申领流程](../CONTRIBUTING.md#申领任务)在原任务 Issue 评论中介绍相关经验、可参与时间和开发条件。
3. 与导师确认目标、交付内容、验收条件和沟通安排；维护者设置 Assignee，并记录申领日期、导师和约定目标。
4. 完成环境准备和任务实践，持续记录进展、问题及验证结果。
5. 按上游社区流程提交成果，处理评审意见。
6. 提交阶段记录，由导师依据[评估标准](assessment.md)完成评估。

## 组织职责

进程使命负责培养安排、导师协调、评估记录和激励公告。伙伴社区可以协助提供课程、任务与导师资源。每期公告列出实际参与的组织、导师和联系方式。

参与者应遵守对应上游社区的行为准则和贡献要求，尊重评审意见，并如实记录成果来源与验证结果。

## 记录要求

每项任务通过 Issue 关联目标、讨论、成果和评估。涉及范围或时间变更时，参与者与导师在 Issue 中记录新安排。暂停或退出任务时，记录当前进展及可交接的资料。

招募时间、名额、参与条件与激励安排以[每期公告](../programs/README.md)为准。
