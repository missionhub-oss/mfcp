# 贡献评估

评估依据任务开始时确认的目标与验收条件，并结合实际贡献、验证证据和协作记录。

| 评估内容 | 审查依据 |
| --- | --- |
| 问题理解 | 背景说明、复现步骤、原因分析与范围判断 |
| 工程质量 | 方案合理性、代码或文档质量、项目规范遵守情况；DCO 按任务要求由作者及导师使用各自真实姓名的英文全称签署，中文姓名使用完整拼音，全部字母大写 |
| 验证质量 | 实际环境、执行命令、结果及适用限制 |
| 社区协作 | 上游讨论、评审回复、修改说明与沟通记录 |
| 成果价值 | 对实际问题的解决程度、可维护性与使用价值 |
| 独立能力 | 独立完成的内容、获得的指导与帮助他人的记录 |

## 评估流程

1. 参与者提交任务目标、成果链接、验证记录和当前上游状态。
2. 导师依据验收条件审查成果，记录已满足条件与仍需完成的事项。
3. 组织者复核评估依据、等级建议及适用的激励条件。
4. 参与者确认记录；有异议时补充证据，由组织者协调复核。

评估结果记录在对应年度的培养记录中，包含任务、评估日期、评估人、结论与依据。公开内容应经过个人信息检查。

上游状态按实际情况记录为讨论中、已提交、修改中、已合并或已关闭。PR 数量只作为活动记录，成果价值通过具体内容判断。上游评审周期以及任务范围变化应纳入评估说明。
