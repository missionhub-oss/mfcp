> 本文件为 MFCP 招聘栏目的示例岗位，用于演示独立 Markdown 岗位文件的字段配置、正文排版、双语切换与目录结构。发布真实岗位时请按 `jobs/README.md` 或 `mfcp-post-job` 技能新增对应的 `jobs/<slug>.md` 文件。

## 岗位职责

- 参与 Linux 内核、Zephyr RTOS 或 QEMU 仿真平台的外设驱动开发、板级支持包（BSP）适配与系统调试。
- 按照上游社区规范整理补丁系列，编写自动化测试用例与技术文档，跟进代码评审直至合入主线。
- 协助社区贡献者定位构建、启动与硬件外设问题，参与开源实践任务设计与技术分享。

## 任职要求

- 熟悉 C 语言与常见嵌入式体系结构（RISC-V / ARM），具备阅读芯片数据手册与原理图的能力。
- 了解 Linux 设备树、驱动模型、RTOS 任务调度或 QEMU 设备建模中的至少一个方向。
- 熟悉 Git 工作流与开源社区协作方式，能够撰写清晰的技术说明与提交记录。

## 方向对照

| 实践方向 | 典型工作内容 | 参考仓库 |
| --- | --- | --- |
| Zephyr RTOS | 外设驱动、板级定义、Twister 测试 | `zephyrproject-rtos/zephyr` |
| Linux Kernel | SoC 适配、驱动调试、内核文档与测试 | `torvalds/linux` |
| QEMU | 板级与 SoC 建模、外设仿真、qtest | `processmission/qemu` |

## 加分项

- 有 Linux、Zephyr、QEMU、Yocto 或 U-Boot 等开源项目上游合入记录。
- 曾参与 MFCP 开源人才培养计划或担任开源社区导师。

## 投递方式

可通过上方投递入口或发送邮件联系，建议一并附上个人简历、GitHub 主页以及代表性开源提交链接。
