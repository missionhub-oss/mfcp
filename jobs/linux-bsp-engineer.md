我们做嵌入式 Linux 操作系统产品，把 OS 交付到机器人、工业控制、边缘计算、IoT 等场景的整机和芯片平台上。这个岗位要解决的核心问题是：让我们的操作系统在各种各样的 SoC 和客户板卡上都能够正确、稳定地启动并运行。你会负责目标平台的 BSP 移植与 Bring-up，是 OS 产品真正落地到硬件上的那一环。

## 岗位职责

1. 负责目标 SoC 平台的 BSP 移植与 Bring-up：完成从板级点亮、启动链路打通到系统稳定的全过程。
2. 负责 U-Boot 的移植、裁剪与启动优化，适配不同启动介质与多阶段引导方案。
3. 负责 Linux 内核的配置裁剪、版本升级与平台适配，维护板级支持代码。
4. 编写与维护设备树（Device Tree），完成板级外设驱动的适配与调试（SPI、I2C、UART、USB、Ethernet、存储等）。
5. 定位并解决内核、驱动与用户态的复杂问题（启动异常、panic、死机、性能与功耗异常），形成可复用的分析结论。
6. 解决跨平台差异带来的适配问题，沉淀移植方法与平台适配文档，支撑下游客户项目与整机厂快速集成。

## 必备条件

- 计算机、电子、通信、自动化等相关专业本科及以上学历。
- 熟练掌握 C 语言，具备扎实的 Linux 系统原理与嵌入式开发基础。
- 有完整的 Linux BSP 移植与板级启动经验，能独立完成新平台、新板卡的 Bring-up。
- 熟悉 U-Boot 移植与配置、内核裁剪与配置、设备树编写。
- 有跨 SoC 平台的适配经历（至少两家芯片厂商或两代平台），能处理平台之间的差异。
- 熟悉 ARM 或 RISC-V 平台的开发与交叉编译调试。
- 熟悉 Git 与 Linux 开发环境，具备良好的代码规范与工程化意识。
- 具备系统级问题分析与定位能力，能独立推进复杂问题解决。

## 优先条件

- 有 Linux 内核层开发或调试经验（能改内核代码、定位到子系统、提交 patch）。
- 有芯片原厂或方案公司的 BSP 交付经验，了解芯片侧交付节奏。
- 有多架构（ARM64、RISC-V）平台适配经验。
- 有 Linux 驱动开发经验（SPI、I2C、UART、CAN、USB、Ethernet 等）。
- 有量产导入、客户现场支持或开源社区贡献经验。
