## Responsibilities

- Develop peripheral drivers, board support packages (BSPs), and system bring-up support for Linux, Zephyr RTOS, or QEMU.
- Prepare upstream-ready patch series with automated tests and documentation, and iterate on maintainer feedback until merge.
- Support community contributors with build, boot, and hardware debugging issues, and collaborate on practical open-source tasks.

## Requirements

- Proficiency in C and embedded architectures (RISC-V / ARM), with the ability to work directly from SoC reference manuals and schematics.
- Hands-on experience in at least one area: Linux device drivers and Device Tree, RTOS fundamentals, or QEMU device modeling.
- Familiarity with Git patch workflows and open-source collaboration practices, with clear written technical communication.

## Track Overview

| Focus Area | Typical Engineering Work | Reference Repository |
| --- | --- | --- |
| Zephyr RTOS | Peripheral drivers, board definitions, Twister tests | `zephyrproject-rtos/zephyr` |
| Linux Kernel | SoC enablement, driver debugging, kernel docs and tests | `torvalds/linux` |
| QEMU | Board and SoC modeling, peripheral emulation, qtest | `processmission/qemu` |

## Nice to Have

- Merged upstream contributions to Linux, Zephyr, QEMU, Yocto, or U-Boot.
- Prior participation or mentoring experience in the Mission Forge Contributor Program (MFCP).
